## VISUAL DESIGN SUMMARY

Five elements that replace text and create the scroll experience:

| Element | Location | What it does |
|---|---|---|
| Scroll-triggered fade-up | Every paragraph and section | Each thought arrives deliberately — nothing dumps at once |
| Pull quote — full width | Section 3 | Visual break + highest-impact line from the origin story |
| Counter animation (0 → 6,000+) | Section 4 | The credential lands as a moment, not a data point |
| ATTUNE dimension pills | Section 4 | Six words light up gold one by one — links to Framework page |
| Photo as mid-page anchor | Section 5 | Breaks the text, adds human presence, creates natural reading pause |
